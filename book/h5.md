## js

1. **download下载某个链接是a链接下载和转成blob格式下载的区别**
   - 方式1：直接通过 a 标签下载

     ```js
     const link = document.createElement('a')
     link.href = this.downloadUrl
     link.download = document.body.appendChild(link)
     link.click()
     document.body.removeChild(link)
     ```

     **流程**

     浏览器直接向服务器发送请求文件：浏览器-url-服务器-返回文件-浏览器下载

     **优点**

     不占用前端内存、大文件下载性能好

     **缺点**

     a.可能跨域失败，需要服务器配置允许下载Access-Control-Allow-Origin、Content-Disposition：attachment下载；浏览器可能直接打开文件而不是下载。

     b.无法拿到文件内容

   - 方式2：先请求，再转 Blob 下载

     ```js
     const res = await fetch(url)
     const blob = await res.blob()
     const blobUrl = URL.createObjectURL(blob)
     const a = document.createElement('a')
     a.href = blobUrl
     a.download = 'test.pdf'
     a.click()

     URL.revokeObjectURL(blobUrl)
     ```

     **流程**

     浏览器fetch-服务器-返回文件流-Blob对象-生成blob地址-a标签下载

     **优点**

     可以拿到响应头、可以获取后端返回的真实文件名、可以鉴权、可以统一处理错误、可以对文件进行处理

     **缺点**
     占内存、大文件可能崩溃、比直接下载多一步

3. SSR Server Side Rendering（服务端渲染）和CSR Client Side Rendering（客户端渲染）
   CSR渲染过程：服务器-空HTML-浏览器-下载js-执行js-渲染页面

   SSR过程：浏览器-请求页面-服务器执行react/vue-生成html-返回完整页面-浏览器直接显示；比如react就用renderToString

   SSR 的 HTML 是服务器在收到请求后，通过执行 React/Vue 组件生成的（renderToString 或流式渲染），然后把生成好的 HTML 返回给浏览器；而 CSR 是浏览器下载 JS 后自己生成 HTML。
